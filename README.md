# 📘 OOPs Concepts in Java

This repository contains **basic and clear examples of Object-Oriented Programming (OOPs) concepts in Java**.  
It is created for **learning, revision, and practice** of core Java fundamentals.

---

## 🧠 Concepts Covered

- 🔹 **Abstraction**
- 🔹 **Encapsulation**
- 🔹 **Inheritance**
- 🔹 **Polymorphism**

Each concept is implemented using **simple Java programs** for better understanding.
